# Historical analytics status

The project keeps descriptive historical analytics based on the supplied EM-DAT extracts. Those records are event/impact summaries rather than validated flood-prediction labels or environmental feature observations. The analytics pipeline is therefore suitable for descriptive reporting, not supervised ML training.

Validated outputs include:

- dataset inventory and provenance
- unique event counts and disaster-type summaries
- year-by-year counts
- approximate geographic coverage
- reported impact totals with coverage warnings

The project intentionally does not treat the historical event records as calibrated flood risk forecasts or as a valid target for live prediction inference.
